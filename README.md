# Vie — Определитель цвета для людей с дальтонизмом

**Vie** — это мобильное приложение на Kotlin с использованием Jetpack Compose, созданное для помощи людям, страдающим дальтонизмом (цветовой слепотой). Приложение позволяет мгновенно определять названия цветов через камеру, проходить тесты на цветовосприятие и симулировать различные типы дальтонизма.

## Реализованный сценарий - определение цвета предмета

На данный момент в приложении реализованы следующие функции:

1.  **Главная навигация:** Реализован нижний навигационный бар с тремя вкладками: `Тест`, `Камера`, `Симуляция`.
2.  **Мгновенное распознавание цвета (Экран "Камера"):**
    - При переходе на вкладку "Камера" запрашивается разрешение на использование камеры.
    - Открывается поток с камеры, в центре экрана отображается прицельная метка (квадрат).
    - **Логика распознавания:** Цвет пикселя в прицельной метке анализируется.
    - **Сопоставление с палитрой:** Полученное RGB-значение сравнивается с предопределенной базой цветов (палитрой). На экран выводится наиболее подходящее название цвета (например, "Красный", "Васильковый").
3.  **Тест и Симуляция:** Созданы заглушки (пустые экраны) для будущих фич "Тест" и "Симуляция дальтонизма".

## База цветов (Мок-данные)

Для сопоставления цветов используется встроенная база данных цветов. Она хранится в формате JSON и загружается из папки `assets`.

- **Файл:** `app/src/main/assets/color_palette.json`
- **Структура:** Файл содержит массив объектов. Каждый объект описывает цвет:
    - `name`: Название цвета на русском языке (отображается пользователю).
    - `r`, `g`, `b`: Значения красного, зеленого и синего каналов (0-255).
    - `radius`: "Радиус" допуска. Чем больше число, тем легче цвет будет определен как этот эталон, даже если оттенок неточный.

Этот файл можно легко расширять, добавляя новые цвета и оттенки без изменения кода приложения.

## Как запустить проект в Android Studio

Следуйте этой инструкции, чтобы открыть и запустить приложение.

### Предварительные требования

- **Android Studio:** Jellyfish | 2023.3.1 или более новая версия (рекомендуется).
- **JDK:** Java Development Kit (версия 11 или 17, обычно встроена в Android Studio).
- **Android SDK:** Убедитесь, что через SDK Manager установлены SDK платформы и инструменты для API уровня 35+ (т.к. `targetSdk = 36`).
- **Устройство:** Физическое Android-устройство (рекомендуется) или эмулятор с поддержкой камеры (для работы основной функции).

### Шаги по запуску

1.  **Клонирование репозитория (если есть):**
    
    Если у вас есть ссылка на Git-репозиторий, склонируйте его:
    ```bash
    git clone [ссылка на ваш репозиторий]
    ```

2.  **Если вы получили проект в виде архива,** просто распакуйте его в удобную папку.

3.  **Открытие проекта:**
    - Запустите Android Studio.
    - В окне приветствия выберите "Open".
    - Найдите и выберите папку `vie-develop` (корневую папку проекта, где находится `settings.gradle.kts`).
    - Нажмите "OK".

4.  **Синхронизация проекта:**
    - Android Studio начнет загрузку зависимостей автоматически. Если этого не произошло, нажмите "Sync Now" в появившейся панели или выберите `File` -> `Sync Project with Gradle Files`.
    - Дождитесь успешного завершения синхронизации.

5.  **Настройка конфигурации запуска:**
    - В верхней панели инструментов убедитесь, что в выпадающем списке выбрана конфигурация "app".
    - Рядом выберите устройство, на котором будете запускать приложение (подключенный телефон или созданный эмулятор).

6.  **Запуск приложения:**
    - Нажмите зеленую кнопку "Run" (треугольник) в верхней панели или выбери `Run` -> `Run 'app'`.
    - Дождитесь сборки проекта и установки приложения на устройство.

### Важно

При первом запуске на реальном устройстве приложение запросит разрешение на использование камеры. Необходимо его предоставить для работы основного функционала.
